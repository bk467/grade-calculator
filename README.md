# grade-calculator

Calculates grade data that you want

# Project Goal

Figuring out gpa and grades required by hand means weighting every course by credit hours and redoing the math whenever a grade changes. This program asks what you want to calculate, asks for only the information it needs, and gives you the answer

## MVP Scope

- Main menu to choose a calculation
- GPA calculator (semester and overalkl)
- Course grade calculator
- Required exam score calculator
- Saves data to a json file and reuses it next time

## Future Plans

- Graph GPA over semesters
- Track multiple semesters
- Show what grades are needed in each class to hit a target GPA

## Tech Stack

- Python 3
- JSON file for storage
- Git and GitHub
